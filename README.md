# Odoo Apps: Spreadsheet

Odoo modules extending the `spreadsheet` module.

## Usage

Clone this repo into the Odoo addons directory.

```bash
git clone git@github.com:Mint-System/Odoo-Apps-Spreadsheet.git ./addons/spreadsheet
```
